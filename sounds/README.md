# Sounds

The recorded notes the app plays, one folder per instrument, every third
semitone from A1 to E♭6.

They come from the **FluidR3_GM** soundfont by Frank Wen, as rendered to
per-note MP3 files by Benjamin Gleitzman's
[midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts), and are
used unmodified under the
[Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/us/)
licence.

| Folder      | Soundfont instrument    |
| ----------- | ----------------------- |
| `piano/`    | `acoustic_grand_piano`  |
| `guitar/`   | `acoustic_guitar_steel` |
| `clarinet/` | `clarinet`              |
